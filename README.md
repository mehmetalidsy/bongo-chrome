# 🐾 Bongo Dev: Chrome Extension

**Bongo Dev**, siz kod yazarken veya internette gezinirken size eşlik eden, klavye ve mouse hareketlerinize duyarlı interaktif bir Bongo Cat eklentisidir. 

## 🚀 Özellikler

- 🎹 **Klavye Duyarlılığı:** Bastığınız her tuşta Bongo Cat ellerini hareket ettirir.
- 🖱️ **Mouse Etkileşimi:** Tıklamalarınıza (Sol, Sağ, Orta) anında tepki verir.
- ⚡ **Performans Odaklı:** Manifest V3 kullanılarak geliştirilmiştir, tarayıcıyı yormaz.
- 🛠️ **Sıfır Bağımlılık:** Herhangi bir dış kütüphane kullanılmadan Vanilla JS ile yazılmıştır.

## 🛠️ Kurulum

Eklenti henüz Chrome Web Mağazası'nda değilse, manuel olarak şu şekilde kurabilirsiniz:

1. Bu depoyu indirin veya clone'layın: `git clone https://github.com/mehmetalidsy/bongo-dev-extension.git`
2. Chrome tarayıcınızı açın ve adres çubuğuna `chrome://extensions/` yazın.
3. Sağ üst köşedeki **Geliştirici Modu**'nu (Developer Mode) aktif hale getirin.
4. **Paketlenmemiş öğe yükle** (Load unpacked) butonuna tıklayın.
5. İndirdiğiniz klasörü seçin.
6. İşte bu kadar! Herhangi bir sayfayı yenileyerek kedinizi görebilirsiniz. 🐾
